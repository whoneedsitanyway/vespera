# Параметры

Все параметры доступны хосту через APVTS. ID указаны в скобках — используются в
коде (`vespera::ids`).

> Числовые значения в полях нобов показываются не более чем с указанным числом
> знаков, хвостовые нули убираются (например `0.35`, `150`, `-12`).

## NOTES (источник материала)

| Контрол   | ID (`ids::`) | Диапазон        | Дефолт   | Описание                                              |
|-----------|--------------|-----------------|----------|-------------------------------------------------------|
| Key       | `key`        | C..B (12)       | C        | Тоника лада                                           |
| Scale     | `scale`      | 10 значений     | Minor    | Лад (см. ниже)                                        |
| Pool      | `poolSize`   | 1..8            | 4        | Сколько последних нот держит пул                      |
| Latch     | `latch`      | вкл/выкл        | выкл     | Заморозить пул (новые ноты игнорируются)              |
| Monitor   | `monitor`    | вкл/выкл        | выкл     | Параллельно играть сыгранные ноты                     |
| Lock Key  | `keyLock`    | вкл/выкл        | выкл     | RANDOM не меняет тональность                          |

### Лады (`Scale::getNames()`)

`Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Harm. Minor,
Pent. Major, Pent. Minor, Chromatic`

> **Note Pool** — это «сырьё» генератора: последние сыгранные ноты (до `Pool`
> штук), квантованные к выбранному ладу. Пока пул пуст, дисплей показывает
> `POOL: play some notes...`, и генератор молчит. **RANDOM** заполняет пул
> аккордом из нового лада автоматически.
>
> **Latch** позволяет убрать руки с клавиатуры — пул перестаёт пополняться, и
> паттерн продолжает строиться из застывшего набора нот.
>
> **Monitor** полезно включать, чтобы слышать, какие именно ноты вы скармливаете
> генератору (с квантованием в лад).
>
> При смене **Key** или **Scale** весь текущий пул **ре-квантуется** в новый лад,
> поэтому генератор не продолжает играть ноты старой тональности.

## PATTERN (генератор)

| Контрол   | ID (`ids::`)  | Диапазон       | Дефолт  | Описание                                         |
|-----------|---------------|----------------|---------|--------------------------------------------------|
| Rate      | `rate`        | 12 значений    | 1/16    | Длительность шага (см. ниже)                     |
| Steps     | `steps`       | 2..16          | 8       | Длина паттерна в шагах                           |
| Density   | `density`     | 0..1           | 0.70    | Вероятность того, что шаг звучит                 |
| Octaves   | `octaves`     | 1..3           | 2       | Разброс октавных прыжков                         |
| Contour   | `contour`     | 6 значений     | Up-Down | Как генератор идёт по пулу (см. ниже)            |
| Mutate    | `mutate`      | 0..1           | 0       | Насколько паттерн эволюционирует за цикл         |
| Swing     | `swing`       | 0..1           | 0       | Смещение нечётных шагов (шафл)                   |
| Gate      | `gate`        | 0.05..1        | 0.50    | Длина ноты как доля шага                         |
| Accent    | `accent`      | 0..1           | 0.30    | Усиление velocity на сильных долях               |
| Transpose | `transpose`   | −7..+7 ступеней| 0       | Транспозиция **по ступеням лада**                |

### Деления шага (`getRateNames()` / `rateInBeats()`)

| Индекс | Значение | Долей (четвертных) |
|--------|----------|--------------------|
| 0      | 1/1      | 4.0                |
| 1      | 1/2      | 2.0                |
| 2      | 1/4      | 1.0                |
| 3      | 1/8      | 0.5                |
| 4      | 1/16     | 0.25               |
| 5      | 1/32     | 0.125              |
| 6      | 1/4T     | 2/3                |
| 7      | 1/8T     | 1/3                |
| 8      | 1/16T    | 1/6                |
| 9      | 1/4D     | 1.5                |
| 10     | 1/8D     | 0.75               |
| 11     | 1/16D    | 0.375              |

Время шага = `60 / BPM × доля × sampleRate` сэмплов. Первые шесть значений
сохраняют исходный порядок, поэтому старые пресеты не меняют темп.

### Контуры (`getContourNames()`)

| Индекс | Значение | Что делает                                        |
|--------|----------|---------------------------------------------------|
| 0      | Up       | Индексы пула по возрастанию (зациклено)           |
| 1      | Down     | Индексы пула по убыванию                          |
| 2      | Up-Down  | «Пинг-понг» по пулу (дефолт)                      |
| 3      | Random   | Случайный индекс (без повтора подряд)             |
| 4      | Walk     | Случайное блуждание шаг за шагом                  |
| 5      | Reverse  | Строит Up и **зеркалит** весь паттерн             |

### Mutate

Каждый раз, когда секвенция возвращается на шаг 0, с вероятностью
`mutate × 0.35` каждый шаг получает **новую ноту из пула** (ритм и активность
сохраняются). Так паттерн никогда не звучит «залупленным», но остаётся
музыкально связным. При `mutate = 0` паттерн не меняется, пока тронута
любая ручка генератора.

### Transpose

Сдвигает всю мелодию на N **ступеней лада**, а не на N полутонов: форма
интервалов сохраняется, ноты остаются в тональности. Отображается в дисплее
как `+3 st`.

## VOICE (полисинтез)

| Контрол  | ID (`ids::`) | Диапазон       | Дефолт   | Описание                                  |
|----------|--------------|----------------|----------|-------------------------------------------|
| Wave     | `wave`       | 4 значения     | Triangle | Sine / Triangle / Saw / Square            |
| Attack   | `attack`     | 0.001..4 с     | 0.005    | Атака огибающей (с skew к 0.05)           |
| Decay    | `decay`      | 0.001..4 с     | 0.25     | Спад до уровня сустейна                   |
| Sustain  | `sustain`    | 0..1           | 0.60     | Уровень сустейна                          |
| Release  | `release`    | 0.01..8 с      | 0.40     | Спад после отпускания                     |
| Detune   | `detune`     | 0..1           | 0.15     | Растройка 2-го осциллятора (0..22 цента)  |

> Голоса: 16, два осциллятора на голос, PolyBLEP на Saw/Square,
> панорама зависит от ноты (`note % 12`), уровень голоса — 0.16 × velocity.

## FILTER (фильтр + модуляция)

| Контрол  | ID (`ids::`)    | Диапазон          | Дефолт | Описание                                   |
|----------|-----------------|-------------------|--------|--------------------------------------------|
| Type     | `filterType`    | Off/LP/BP/HP      | LP     | Тип фильтра (TPT SVF, 12 дБ/окт)           |
| Cutoff   | `filterCutoff`  | 30..18000 Гц      | 8000   | Частота среза (skew к 1200 Гц)             |
| Reso     | `filterReso`    | 0..1              | 0.15   | Резонанс (Q 0.707 → ≈16)                   |
| Env      | `filterEnv`     | 0..1              | 0.20   | Огибающая входа → срез (до 3 октав)        |
| LFO      | `lfoShape`      | 7 значений        | Sine   | Форма модуляции                            |
| Sync     | `lfoSync`       | вкл/выкл          | выкл   | LFO по темпу хоста (блокирует RATE)        |
| Division | `lfoRate`       | 8 делений         | 1/1    | Деление LFO при включённом Sync            |
| Rate     | `lfoRateHz`     | 0.02..20 Гц       | 1.00   | Свободная частота LFO                      |
| Motion   | `motion`        | 0..1              | 0.10   | Глубина LFO в срез (до 2 октав)            |

### Формы LFO (`Lfo::getNames()`)

`Sine, Triangle, Saw Up, Saw Down, Square, Random, Walk`

- **Random** — новое значение на каждом цикле;
- **Walk** — плавное случайное блуждание к новой цели.

### Деления LFO (при Sync)

| Индекс | Значение | Долей |
|--------|----------|-------|
| 0      | 4/1      | 16.0  |
| 1      | 2/1      | 8.0   |
| 2      | 1/1      | 4.0   |
| 3      | 1/2      | 2.0   |
| 4      | 1/4      | 1.0   |
| 5      | 1/8      | 0.5   |
| 6      | 1/16     | 0.25  |
| 7      | 1/32     | 0.125 |

> Пока **Sync** включён, ручка **RATE** приглушена и неактивна — частота LFO
> берётся из BPM хоста (по образцу блокировки TIME при SYNC в Lunara).

## CHARACTER (материал звука)

| Контрол | ID (`ids::`) | Диапазон | Дефолт | Описание                                        |
|---------|--------------|----------|--------|-------------------------------------------------|
| Drive   | `drive`      | 0..1     | 0      | Тангенциальная сатурация («ленточная»)          |
| Crush   | `crush`      | 0..1     | 0      | Бит-краш + reduction частоты дискретизации      |
| Noise   | `noise`      | 0..1     | 0      | Хисс и виниловые трески (гейт по нотам)         |
| Wow     | `wow`        | 0..1     | 0      | Tape wow & flutter (линия задержки)             |
| Fold    | `fold`       | 0..1     | 0      | Wave folding (от мягких гармоник до металла)    |
| Ring    | `ring`       | 0..1     | 0      | Ring modulation (тремоло → сайдбэнды)           |

> Все ручки квадратично-плавные: первые положения тонкие, резкость растёт
> к концу диапазона. При нуле всех шести ручек каскад **полностью
> пропускается** (экономия CPU и нулевая задержка).

## OUTPUT

| Контрол     | ID (`ids::`)     | Диапазон    | Дефолт | Описание                                  |
|-------------|------------------|-------------|--------|-------------------------------------------|
| Output      | `output`         | −24..+12 дБ | 0      | Выходная громкость (сглажена, 20 мс)      |
| Limiter     | `limiter`        | вкл/выкл    | вкл    | Пиковый лимитер на выходе                 |
| Play Sync   | `transportSync`  | вкл/выкл    | вкл    | Генератор идёт только приplaying хоста    |

### Limiter

Прозрачный стерео-связанный пиковый лимитер (атака ~1 мс, релиз ~120 мс),
потолок 0.98, сверх потолка — **мягкий `tanh`**, поэтому выброс, проскочивший
за время атаки, ограничивается плавно. Снятая галочка **полностью обходит**
каскад, но финальный предохранитель всё равно клампит выход к ±1.0.

### Play Sync

При включённой галочке генератор запускается только когда транспорт хоста
**играет**, и останавливается при стопе (сбрасываясь на первый шаг, чтобы
каждая «дубль» начиналась одинаково). **Standalone** и хосты без playhead
всегда играют свободно — инструмент не может «загадочно молчать».

При остановленном транспорте синтез продолжает рендериться: ноты **Monitor**
и хвосты релиза слышны, но паттерн не двигается.

## RANDOM

Кнопка **RANDOM** вызывает `randomizeParameters()`:

- **Key / Scale** — новый тонус и лад (не трогается при **Lock Key**);
- **Pattern** — Rate, Steps, Density (0.45..0.95), Octaves, Contour,
  Swing, Gate (0.25..0.75), Accent;
- **Filter** — тип выбирается взвешенно (LP 55 %, BP 27 %, HP 11 %, Off 7 %),
  и для каждого типа свой **музыкальный** диапазон среза (BP — 300..1500 Гц,
  HP — 50..220 Гц), чтобы RANDOM не приводил к тихой/глухой настройке.
  Sine-волна запрещена при BP/HP (нет гармоник), вместо неё Triangle/Saw/Square;
- **Voice** — Wave, Attack, Decay, Sustain, Release, Detune;
- **Character** — Drive, Crush, Wow, Fold, Ring;
- **Output** — всегда 0 дБ;
- **Note Pool** — засевается аккордом из нового лада (тоника обязательна),
  поэтому сразу слышно результат.

> **Не трогает**: `mutate`, `transpose`, `noise` (намеренный выбор),
> `limiter`, `transportSync`, `latch`, `monitor`, `poolSize`.

## UI / режимы отображения

- **Хедер**: слева — окошко **пресетов** + иконки **Save**, **темы** и **LOG**;
  справа — `RANDOM`, `COMPACT`, `MIDI`. В шапке справа — версия плагина
  (`v1.0.0`).
- **COMPACT / FULL** — скрывает `PatternDisplay`, окно 1280×820 → 1280×600.
- **MIDI** — кнопка-драг: записывает текущий паттерн в Standard MIDI File
  и начинает drag, чтобы её можно было бросить прямо в дорожку секвенсора.
  Одиночный клик — показать файл в Finder.
- **PatternDisplay** (внизу): заголовок с пулом нот, тональностью, транспозицией,
  BPM и числом голосов; сетка шагов (высота = velocity, подпись = нота),
  подсветка текущего шага, при остановленном транспорте —
  `waiting for transport`.
- **Тема**: иконка (солнце/луна) переключает тёмную и мягкую светлую;
  выбор сохраняется в `~/Library/Application Support/Vespera/theme.txt`.
- **LOG** — открывает `~/Library/Application Support/Vespera/vespera_debug.log`.
  Красный бейдж = пойманная аномалия.
- **Подсказки** — при наведении на любой контрол всплывает описание (English,
  ~650 мс).

## Пресеты

Пресеты хранятся как XML-файлы (`*.vesperapreset`) в
`~/Library/Application Support/Vespera/Presets`. Выбор в окошке сразу загружает
состояние; иконка сохранения открывает диалог с именем.

### Заводские (factory) пресеты

Вшиты в бинарь (`Source/FactoryPresets.h`), версия 7, всегда доступны:

`First Light`, `Rain Arp`, `Broken Music Box`, `Deep Pulse`,
`Glass Steps`, `Tape Lullaby`, `Acid Walk`, `Frozen Motif`.

При первом запуске (и при росте `kFactoryPresetVersion`) они переустанавливаются
в пользовательский каталог; удалённый файл загружается из вшитой копии.

**При открытии свежего экземпляра** применяется **`First Light`**;
восстановленный хостом проект не перезаписывается.

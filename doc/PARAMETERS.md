# Параметры

Все параметры доступны хосту через APVTS. ID указаны в скобках — используются в
коде (`vespera::ids`).

> Числовые значения в полях нобов показываются не более чем с указанным числом
> знаков, хвостовые нули убираются (например `0.35`, `150`, `-12`).

## NOTES (источник материала)

| Контрол   | ID (`ids::`) | Диапазон        | Дефолт   | Описание                                              |
|-----------|--------------|-----------------|----------|-------------------------------------------------------|
| Key       | `key`        | C..B (12)       | C        | Тоника лада                                           |
| Scale     | `scale`      | 10 значений     | Minor    | Лад (см. ниже)                                        |
| Pool      | `poolSize`   | 1..8            | 4        | Сколько последних нот держит пул                      |
| Latch     | `latch`      | вкл/выкл        | выкл     | Заморозить пул (новые ноты игнорируются)              |
| Monitor   | `monitor`    | вкл/выкл        | выкл     | Параллельно играть сыгранные ноты                     |
| Lock Key  | `keyLock`    | вкл/выкл        | выкл     | RANDOM не меняет тональность                          |

### Лады (`Scale::getNames()`)

`Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Harm. Minor,
Pent. Major, Pent. Minor, Chromatic`

> **Note Pool** — это «сырьё» генератора: последние сыгранные ноты (до `Pool`
> штук), квантованные к выбранному ладу. Пока пул пуст, дисплей показывает
> `POOL: play some notes...`, и генератор молчит. **RANDOM** заполняет пул
> аккордом из нового лада автоматически.
>
> **Latch** позволяет убрать руки с клавиатуры — пул перестаёт пополняться, и
> паттерн продолжает строиться из застывшего набора нот.
>
> **Monitor** полезно включать, чтобы слышать, какие именно ноты вы скармливаете
> генератору (с квантованием в лад).
>
> При смене **Key** или **Scale** весь текущий пул **ре-квантуется** в новый лад,
> поэтому генератор не продолжает играть ноты старой тональности.

|-----------|---------------|----------------|---------|--------------------------------------------------|

| Steps     | `steps`       | 2..16          | 8       | Длина паттерна в шагах                           |
| Density   | `density`     | 0..1           | 0.70    | Сколько шагов мотива звучит (по метрическим весам) |
| Octaves   | `octaves`     | 1..3           | 2       | Октавный сдвиг **на фразу**, а не на ноту        |
| Contour   | `contour`     | 6 значений     | Up-Down | Как генератор идёт по пулу (см. ниже)            |
| Mutate    | `mutate`      | 0..1           | 0       | Насколько паттерн эволюционирует за цикл         |
| Swing     | `swing`       | 0..1           | 0       | Смещение нечётных шагов (шафл)                   |
| Gate      | `gate`        | 0.05..1        | 0.50    | Длина ноты как доля шага                         |
| Accent    | `accent`      | 0..1           | 0.30    | Усиление velocity на сильных долях               |
| Transpose | `transpose`   | −7..+7 ступеней| 0       | Транспозиция **по ступеням лада**                |

### Деления шага (`getRateNames()` / `rateInBeats()`)

| Индекс | Значение | Долей (четвертных) |
|--------|----------|--------------------|
| 0      | 1/1      | 4.0                |
| 1      | 1/2      | 2.0                |
| 2      | 1/4      | 1.0                |
| 3      | 1/8      | 0.5                |
| 4      | 1/16     | 0.25               |
| 5      | 1/32     | 0.125              |
| 6      | 1/4T     | 2/3                |
| 7      | 1/8T     | 1/3                |
| 8      | 1/16T    | 1/6                |
| 9      | 1/4D     | 1.5                |
| 10     | 1/8D     | 0.75               |
| 11     | 1/16D    | 0.375              |

Время шага = `60 / BPM × доля × sampleRate` сэмплов. Первые шесть значений
сохраняют исходный порядок, поэтому старые пресеты не меняют темп.

### Контуры (`getContourNames()`)

| Индекс | Значение | Что делает                                        |
|--------|----------|---------------------------------------------------|
| 0      | Up       | Ступени пула по возрастанию (считаются сыгранные ноты) |
| 1      | Down     | Ступени пула по убыванию                          |
| 2      | Up-Down  | «Пинг-понг» по пулу (дефолт)                      |
| 3      | Random   | Случайный индекс (шаг ±1/±2, без повтора подряд)  |
| 4      | Walk     | Случайное блуждание шаг за шагом                  |
| 5      | Reverse  | Строит Up и **зеркалит** весь паттерн             |

### Фраза, а не поток нот

Генератор строит не независимые ноты, а **мотив** и его вариации:

- **Мотив** — первые `motifLength` шагов: 4 при `steps ≥ 12`, иначе половина
  паттерна (минимум 2). Схема повторов — A B A C: чётные секции играют мотив
  как есть, нечётные — одну из вариаций.
- **Вариации** — диатоническая транспозиция на ±2 ступени, сдвиг ритмической
  маски на шаг и ретроград (зеркалится и ритм, и высоты). Транспозиция
  используется только когда все ноты мотива ложатся в пул (допускается сдвиг
  до 3 полутонов, без схлопывания двух нот в одну); иначе ответ строится
  ритмическим сдвигом.
- **Ритм** — маска выбирается на длину мотива взвешенно по метрическим весам
  (сильная доля 1.0, четверть 0.80, восьмая 0.55, остальное 0.30). `density`
  задаёт точное число звучащих шагов мотива, а не вероятность для каждого шага.
- **Скачки** — не больше квинты для свободных контуров и октавы для
  Up/Down/Up-Down; после скачка на 5+ полутонов следующий шаг идёт назад
  (классическое правило мелодии).
- **Октава** — принадлежит фразе: внутри секции все ноты имеют один и тот же
  октавный сдвиг. При `octaves ≥ 2` вариация может поднять секцию на октаву.
- **Каденция** — последняя звучащая нота прижимается к устойчивой ступени
  (тоника, терция, квинта — в пентатонике тоже, по интервалу, а не по номеру
  ступени). Если тоника пула рядом (в пределах квинты), каденция садится
  именно на неё: терция и квинта устойчивы, но оставляют фразу открытой.
  Начала тактов — к аккордовым тонам в пределах 2 полутонов.
- **Гармония** — окраска аккорда (септима, обращение) одна на такт (4 шага);
  корень следует за мелодией, поэтому аккорды двигаются вместе с линией.
  Септима чаще появляется в такте перед каденцией, последний такт — без
  септимы и в основном виде.

### Mutate

Каждый раз, когда секвенция возвращается на шаг 0, с вероятностью
`mutate × 0.35` шаг сдвигается на **соседнюю ступень пула** (±1), а не на
случайную ноту. Ритм, длина мотива и структура фразы сохраняются, поэтому
паттерн развивается, но не распадается. При `mutate = 0` паттерн не меняется,
пока тронута любая ручка генератора.

### Transpose

Сдвигает всю мелодию на N **ступеней лада**, а не на N полутонов: форма
интервалов сохраняется, ноты остаются в тональности. Отображается в дисплее
как `+3 st`.

## VOICE (полисинтез)

| Контрол  | ID (`ids::`) | Диапазон       | Дефолт   | Описание                                  |
|----------|--------------|----------------|----------|-------------------------------------------|
| Wave     | `wave`       | 4 значения     | Triangle | Sine / Triangle / Saw / Square            |
| Attack   | `attack`     | 0.001..4 с     | 0.005    | Атака огибающей (с skew к 0.05)           |
| Decay    | `decay`      | 0.001..4 с     | 0.25     | Спад до уровня сустейна                   |
| Sustain  | `sustain`    | 0..1           | 0.60     | Уровень сустейна                          |
| Release  | `release`    | 0.01..8 с      | 0.40     | Спад после отпускания                     |
| Detune   | `detune`     | 0..1           | 0.15     | Растройка 2-го осциллятора (0..22 цента)  |
| Tape     | `tape`       | 0..1           | 0        | Один музыкальный макрос «магнитной ленты»  |

> Голоса: 24, два осциллятора на голос, PolyBLEP на Saw/Square,
> панорама зависит от ноты (`note % 12`), уровень голоса — 0.16 × velocity.

### Tape

Раньше раздел CHARACTER давал шесть независимых ручек (Drive, Crush, Noise,
Wow, Fold, Ring). Они перцептивно перекрывались: низ диапазона почти не
слышен, верх — разрушает мелодию. Теперь это **одна** ручка с музыкальной
кривой:

- **0** — каскад полностью обходится (bit-transparent, без задержки);
- **низ** — мягкий спад верха (20 кГц → 5 кГц по диапазону) и лёгкая
  сатурация: ручка слышна уже с первых процентов;
- **середина** — тёплая компрессия и лёгкий дрейф высоты;
- **верх** — wow/flutter не более ~8 центов (pitch остаётся рабочим),
  сатурация ограничена мягким tanh, хисс появляется только после 0.3,
  гейтится огибающей нот и низкочастотен.

Хисс намеренно не рандомизируется: это осознанный выбор пользователя.

## SECOND VOICE (второй голос)

| Контрол   | ID (`ids::`)    | Диапазон | Дефолт | Описание                                      |
|-----------|-----------------|----------|--------|-----------------------------------------------|
| Role      | `secondRole`    | 0..5     | Off    | Off / Answer / Bass / Harmony / Octave / Drone |
| Interval  | `secondInterval`| 0..4     | 1      | Unison / 3rd / 4th / 5th / 6th                 |
| Register  | `secondOctave`  | −2..+2   | 0      | Октавный сдвиг второго голоса                  |
| Offset    | `secondOffset`  | 0..8     | 2      | На сколько шагов Answer отстаёт от лида        |
| Density   | `secondDensity` | 0..1     | 0.5    | Как часто играет второй голос                  |
| Level     | `secondLevel`   | 0..1     | 0.6    | Velocity второго голоса относительно лида      |

Роли:

- **Answer** — независимая линия из второго `PatternEngine` (свой контур и
  плотность), задержанная на `Offset` шагов: голоса перекликаются фразами.
  `Interval` диатонически транспонирует линию ответа вниз (Unison — как
  сгенерировано).
- **Bass** — корень текущего шага на октаву ниже (при Register 0), на
  сильных долях; Density задаёт период (каждый 1-й…4-й шаг).
- **Harmony** — диатоническая терция/кварта/квинта/секста ниже лида, всегда
  в выбранном ладу; `Interval` выбирает ступень.
- **Octave** — дублирование лида на октаву выше.
- **Drone** — выдержанная педаль на тонике лада; Density задаёт период
  перезапуска (1…8 шагов), нота звучит до следующего триггера. `Interval`
  поднимает педаль по ступеням лада (квинта выше тоники — открытый дрон).

Второй голос не является эффектом: он не обрабатывает звук, а добавляет
нотные события. Поэтому он попадает в дисплей (тонкая линия поверх бара) и
в MIDI-экспорт отдельной дорожкой.

> **Какие ручки что делают.** `Offset` двигает только линию **Answer**.
> `Interval` работает для **Answer** (сдвиг линии ответа вниз), **Harmony**
> (ступень ниже лида) и **Drone** (ступень выше тоники). У остальных ролей —
> Bass, Octave и Off — эти контролы затемняются и отключаются, чтобы не
> выглядеть «живыми», когда они ни на что не влияют. `Register`, `Density` и
> `Level` работают для всех ролей, кроме **Off** (при Off они тоже затемняются).
>
> `Interval = Unison` означает «не сдвигать»: для Answer это линия ровно как
> сгенерирована, для Harmony — дубль лида, для Drone — педаль на тонике.
>
> `Offset` считается по кругу паттерна: при 8 шагах значения 0 и 8 дают
> одинаковый результат, при 4 шагах совпадают 0, 4 и 8 — это не поломка, а
> модуль длины фразы.
>
> Снапшот для дисплея пересобирается и при остановленном транспорте (Play Sync),
> поэтому поворот Role/Offset/Interval сразу меняет картинку, а не ждёт
> следующего шага.

## FILTER (фильтр + модуляция)

Фильтр стоит **внутри каждого голоса**: у каждой ноты своя огибающая среза,
поэтому акценты и аккорды не «смазываются» в одно значение громкости. Общий на
все голоса — только LFO.

| Контрол  | ID (`ids::`)    | Диапазон          | Дефолт | Описание                                      |
|----------|-----------------|-------------------|--------|-----------------------------------------------|
| Type     | `filterType`    | Off/LP/BP/HP      | LP     | Тип фильтра (TPT SVF, 12 дБ/окт)              |
| Cutoff   | `filterCutoff`  | 30..18000 Гц      | 8000   | Частота среза (skew к 1200 Гц)                |
| Reso     | `filterReso`    | 0..1              | 0.15   | Резонанс (Q 0.707 → ≈16)                      |
| Env      | `filterEnv`     | 0..1              | 0.35   | Огибающая **ноты** → срез (до 3 октав)        |
| Key      | `filterKey`     | 0..1              | 0.50   | Key tracking: верхние ноты ярче (0..1 = 0..1 окт/окт) |
| Velo     | `filterVel`     | 0..1              | 0.40   | Velocity → срез: жёсткие ноты ярче            |
| LFO      | `lfoShape`      | 7 значений        | Sine   | Форма модуляции                               |
| Sync     | `lfoSync`       | вкл/выкл          | выкл   | LFO по темпу хоста (блокирует RATE)           |
| Division | `lfoRate`       | 8 делений         | 1/1    | Деление LFO при включённом Sync               |
| Rate     | `lfoRateHz`     | 0.05..10 Гц       | 1.00   | Свободная частота LFO                         |
| Motion   | `motion`        | 0..1              | 0.35   | Глубина LFO в срез (до 2.5 октав)             |

Огибающая среза имеет собственные фиксированные времена: атака 4 мс,
спад 300 мс, сустейн 0.25, релиз 200 мс — короткая «открывашка» на каждую ноту,
независимая от ADSR громкости.

**Off** полностью прозрачен (выход = вход), но огибающая продолжает считаться,
чтобы при включении фильтр стартовал с корректного значения.

### Формы LFO (`Lfo::getNames()`)

`Sine, Triangle, Saw Up, Saw Down, Square, Random, Walk`

- **Random** — новое значение на каждом цикле;
- **Walk** — плавное случайное блуждание к новой цели.

### Деления LFO (при Sync)

| Индекс | Значение | Долей |
|--------|----------|-------|
| 0      | 4/1      | 16.0  |
| 1      | 2/1      | 8.0   |
| 2      | 1/1      | 4.0   |
| 3      | 1/2      | 2.0   |
| 4      | 1/4      | 1.0   |
| 5      | 1/8      | 0.5   |
| 6      | 1/16     | 0.25  |
| 7      | 1/32     | 0.125 |

> Пока **Sync** включён, ручка **RATE** приглушена и неактивна — частота LFO
> берётся из BPM хоста (по образцу блокировки TIME при SYNC в Lunara).

## OUTPUT

| Контрол     | ID (`ids::`)     | Диапазон    | Дефолт | Описание                                  |
|-------------|------------------|-------------|--------|-------------------------------------------|
| Output      | `output`         | −24..+12 дБ | 0      | Выходная громкость (сглажена, 20 мс)      |
| Limiter     | `limiter`        | вкл/выкл    | вкл    | Пиковый лимитер на выходе                 |
| Chords      | `chords`         | вкл/выкл    | выкл   | Каждый шаг играет аккорд из выбранного лада |
| Play Sync   | `transportSync`  | вкл/выкл    | вкл    | Генератор идёт только при играющем транспорте |

### Limiter

Прозрачный стерео-связанный пиковый лимитер (атака ~1 мс, релиз ~120 мс),
потолок 0.98, сверх потолка — **мягкий `tanh`**, поэтому выброс, проскочивший
за время атаки, ограничивается плавно. Снятая галочка **полностью обходит**
каскад, но финальный предохранитель всё равно клампит выход к ±1.0.

### Chords

Каждый активный шаг играет не одну ноту, а **диатонический аккорд**, построенный
от ноты шага:

- основа — трезвучие (тоника, терция, квинта) **по ступеням выбранного лада**,
  поэтому все ноты гарантированно остаются в тональности; в пентатонике терция
  и квинта находятся по интервалу, а не по номеру ступени, поэтому аккорд —
  настоящее трезвучие, а не квартовый стек;
- примерно в 30 % тактов добавляется септима — мажорный/минорный септаккорд,
  доминантсептаккорд или уменьшённый;
- примерно в 30 % средних тактов используется обращение: нижняя нота
  поднимается на октаву, чтобы прогрессия не звучала как параллельные
  трезвучия;
- громкость голосов делится на `sqrt(N)`, поэтому включение Chords не даёт
  скачка уровня;
- в хроматике — мажорные/минорные трезвучия (диатонических терций там нет).

Аккорд описывается маской и обращением в `PatternStep`, поэтому синтез,
дисплей и MIDI-экспорт всегда воспроизводят один и тот же аккорд.

### Play Sync

При включённой галочке генератор запускается только когда транспорт хоста
**играет**, и останавливается при стопе (сбрасываясь на первый шаг, чтобы
каждая «дубль» начиналась одинаково). **Standalone** и хосты без playhead
всегда играют свободно — инструмент не может «загадочно молчать».

При остановленном транспорте синтез продолжает рендериться: ноты **Monitor**
и хвосты релиза слышны, но паттерн не двигается.

## RANDOM

Кнопка **RANDOM** вызывает `randomizeParameters()`:

- **Key / Scale** — новый тонус и лад (не трогается при **Lock Key**);
- **Pattern** — Rate, Steps, Density (0.45..0.95), Octaves, Contour,
  Swing, Gate (0.25..0.75), Accent;
- **Filter** — тип выбирается взвешенно (LP 55 %, BP 27 %, HP 11 %, Off 7 %),
  и для каждого типа свой **музыкальный** диапазон среза (BP — 300..1500 Гц,
  HP — 50..220 Гц), чтобы RANDOM не приводил к тихой/глухой настройке.
  Env, Motion и Rate тоже получают диапазон под тип, Key (0.2..0.9) и
  Velo (0.2..0.7) — чтобы каждая нота заметно открывала фильтр.
  Sine-волна запрещена при BP/HP (нет гармоник), вместо неё Triangle/Saw/Square;
- **Voice** — Wave, Attack, Decay, Sustain, Release, Detune;
- **Second Voice** — Role (40 % Off, 20 % Answer, 12 % Bass, 12 % Harmony,
  10 % Octave, 6 % Drone), Interval (3rd чаще всего), Register, Offset,
  Density, Level;
- **Output** — всегда 0 дБ;
- **Note Pool** — засевается аккордом из нового лада (тоника обязательна),
  поэтому сразу слышно результат.

> **Не трогает**: `mutate`, `transpose`, `tape` (намеренный выбор),
> `chords`, `limiter`, `transportSync`, `latch`, `monitor`, `poolSize`.

## UI / режимы отображения

- **Хедер**: слева — окошко **пресетов** + иконки **Save**, **темы** и **LOG**;
  справа — `RANDOM`, `COMPACT`, `MIDI`. В шапке справа — версия плагина
  (`v1.0.0`).
- **COMPACT / FULL** — скрывает `PatternDisplay`, окно 1280×820 → 1280×600.
- **MIDI** — кнопка-драг: записывает текущий паттерн в Standard MIDI File
  и начинает drag, чтобы её можно было бросить прямо в дорожку секвенсора.
  Одиночный клик — показать файл в Finder.
- **PatternDisplay** (внизу): заголовок с пулом нот, тональностью, транспозицией,
  BPM и числом голосов; сетка шагов (высота = velocity, подпись = нота),
  при включённых **Chords** — блок аккорда с линейками тонов,
  подсветка текущего шага, при остановленном транспорте —
  `waiting for transport`.
- **Тема**: иконка (солнце/луна) переключает тёмную и мягкую светлую;
  выбор сохраняется в `~/Library/Application Support/Vespera/theme.txt`.
- **LOG** — открывает `~/Library/Application Support/Vespera/vespera_debug.log`.
  Красный бейдж = пойманная аномалия.
- **Подсказки** — при наведении на любой контрол всплывает описание (English,
  ~650 мс).

## Пресеты

Пресеты хранятся как XML-файлы (`*.vesperapreset`) в
`~/Library/Application Support/Vespera/Presets`. Выбор в окошке сразу загружает
состояние; иконка сохранения открывает диалог с именем.

### Заводские (factory) пресеты

Вшиты в бинарь (`Source/FactoryPresets.h`), версия 8, всегда доступны:

`First Light`, `Rain Arp`, `Broken Music Box`, `Deep Pulse`,
`Glass Steps`, `Tape Lullaby`, `Acid Walk`, `Frozen Motif`.

При первом запуске (и при росте `kFactoryPresetVersion`) они переустанавливаются
в пользовательский каталог; удалённый файл загружается из вшитой копии.

**При открытии свежего экземпляра** применяется **`First Light`**;
восстановленный хостом проект не перезаписывается.

# Vespera — генератор мелодических идей

> Рабочее название проекта: **Vespera**. Идея — «инструмент, который придумывает
> мелодии за вас»: генератор паттернов, полифонический синтезатор, модульный
> фильтр с LFO, эффект-стейдж Character и MIDI-вывод — всё в одном плагине.

## Что это

Vespera — это **синтезатор-генератор мелодий** для sound design и эмбиента.
Вы подаёте на вход несколько нот (или ждёте автоматического семплинга),
а плагин генерирует бесконечно эволюционирующие мелодические фигуры в
выбранном ладу, с характером и модуляцией.

## Текущий статус

- Версия: `1.0.0` — релиз: собирается, все офлайн-тесты зелёные.
- Форматы: **VST3**, **AU**, **Standalone**.
- AU проходит `auval` (`AU VALIDATION SUCCEEDED`).
- Реализованы:
  - **Note Pool** — память последних N сыгранных нот, квантованных к ладу.
  - **Pattern Engine** — генератор музыкальных фраз: короткий мотив с повтором
    и вариациями, ритм по метрическим весам, ограничение скачков, каденция на
    устойчивой ступени (6 контуров, плотность, октавы по секциям, мутация,
    свинг, гейт, акцент, транспозиция по ступеням).
  - **PolySynth** — полифонический движок (24 голоса, 2 детюне-осциллятора
    с PolyBLEP, ADSR, панорамирование по нотам).
  - **Chords** — каждый шаг может играть диатонический аккорд из выбранного
    лада (трезвучия, септимы, обращения).
  - **Resonant Filter** — TPT state-variable фильтр (LP/BP/HP) с огибающей
    входа и LFO-модуляцией.
  - **LFO** — 7 форм (sine, triangle, saw, square, random, walk),
    свободный (Гц) или синхронный (нотные деления).
  - **Character** — tape wow/flutter, сатурация, бит-краш, шум,
    wave folding, ring modulation.
  - **Output Limiter** — прозрачный пиковый лимитер с мягким потолком.
  - **Play Sync** — генератор работает только пока транспорт хоста играет.
  - **MIDI-экспорт** — перетаскивание текущего паттерна как SMF в DAW.
  - **8 заводских пресетов** (First Light — по умолчанию).
  - **Светлая/тёмная тема**, компактный режим, паттерн-дисплей.
  - **Чёрный ящик (DebugLogger)**: журнал уровней по каскадам с автовыгрузкой
    истории при аномалии (`~/Library/Application Support/Vespera/vespera_debug.log`),
    кнопка **LOG** в хедере и красный индикатор пойманного сбоя.

## Быстрый старт

```bash
cd ~/Vespera
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Артефакты и места установки:

| Формат     | Путь                                                                 |
|------------|----------------------------------------------------------------------|
| VST3       | `~/Library/Audio/Plug-Ins/VST3/Vespera.vst3`                         |
| AU         | `~/Library/Audio/Plug-Ins/Components/Vespera.component`              |
| Standalone | `build/Vespera_artefacts/Release/Standalone/Vespera.app`             |

Подробности по сборке — в [DEVELOPMENT.md](DEVELOPMENT.md).

# Roadmap

## Сделано (v1.0.0)

### Каркас и форматы

- [x] CMake + JUCE 8.0.6 (`FetchContent`), опция `VESPERA_JUCE_DIR` для локального checkout.
- [x] Форматы VST3 / AU / Standalone, `COPY_PLUGIN_AFTER_BUILD TRUE`.
- [x] Инструмент (`IS_SYNTH`), принимает MIDI, стерео-выход, нулевая задержка.
- [x] Валидация AU (`auval -v aumu Vspa Strv`).
- [x] `.gitignore` (build/, IDE, .DS_Store).

### Генератор мелодий

- [x] **Scale** — 10 ладов (Major…Chromatic), квантование в лад, `isInScale`.
- [x] **Транспозиция по ступеням** (`transposeDegrees`) — форма мелодии
      сохраняется, ноты остаются в тональности.
- [x] **NotePool** — FIFO последних нот (до 16 слотов, ручка Pool 1..8),
      дубликаты отбрасываются, корректное сужение/расширение пула.
- [x] **Latch** — заморозка пула: генератор продолжает играть без клавиатуры.
- [x] **PatternEngine** — 2..16 шагов, density, октавы 1..3,
      6 контуров (Up / Down / Up-Down / Random / Walk / Reverse).
- [x] **Reverse** — строрует фигуру как Up и зеркалит паттерн (ритм + мелодия).
- [x] **Mutate** — мягкая эволюция высоты в конце каждого цикла (ритм сохраняется).
- [x] **Accent** — усиление velocity на сильных долях (каждый 4-й шаг).
- [x] **Swing** — шафл нечётных шагов (×1.5 при максимумe).
- [x] **Gate** — длина ноты как доля шага.
- [x] **12 делений шага** — прямые (1/1…1/32), триоли (1/4T…1/16T),
      пунктиры (1/4D…1/16D); порядок первых шести зафиксирован,
      чтобы старые пресеты не меняли темп.
- [x] `ensurePlayable()` — паттерн никогда не бывает пустым при density > 0
      (первый шаг всегда жив): Random больше не даёт «мёртые» пресеты.
- [x] Мгновенная пересборка паттерна при движении Density / Octaves /
      Contour / Accent / Pool (ручки чувствуются живыми, а не с задержкой
      до следующего цикла).
- [x] Ре-квантование пула при смене Key/Scale — генератор не играет ноты
      старой тональности.

### Синтез и обработка

- [x] **PolySynth** — 16 голосов, 2 осциллятора на голос (Sine/Triangle/Saw/Square),
      **PolyBLEP** на разрывных формах, ADSR, voice stealing по возрасту.
- [x] **Detune** (0..22 цента) и **панорама по ноте** (cos/sin law, ±0.7).
- [x] **ResonantFilter** — TPT state-variable (Off/LP/BP/HP), резонанс до Q≈16,
      env follower (2 мс / 180 мс) до +3 октав, мягкий потолок tanh.
- [x] **LFO** — 7 форм (Sine, Triangle, Saw Up, Saw Down, Square, Random, Walk),
      свободная частота 0.02..20 Гц или синк к темпу (8 делений 4/1…1/32),
      глубина Motion (до ±2 октав).
- [x] **Character** — Drive (ленточная сатурация), Crush (бит + SR-редукция),
      Noise (хисс + виниловые трески, гейт по огибающей нот),
      Wow (tape wow & flutter, стерео-расхождение), Fold (wavefolder),
      Ring (35…935 Гц: тремоло → металлический сайдбэнд).
- [x] Квадратичные кривые Crush/Noise — первые положения тонкие.
- [x] Early-exit всего Character-каскада при нулевых ручках (нет аллокаций,
      нет задержки, экономия CPU).
- [x] **Output** −24..+12 дБ со сглаживанием 20 мс (без щелчков при свипе).
- [x] **Limiter** — прозрачный стерео-связанный пиковый лимитер (1 мс / 120 мс),
      потолок 0.98, мягкий tanh-потолок, съём gain reduction в лог.

### Транспорт и MIDI

- [x] **Play Sync** — генератор идёт только при играющем транспорте;
      при старте паттерн начинается с первого шага (дубли стартуют одинаково).
- [x] Standalone / хосты без playhead — всегда free-run (инструмент не молчит).
- [x] При остановке транспорта голоса и **Monitor** продолжают звучать,
      хвосты релиза не обрезаются, паттерн не двигается.
- [x] **Monitor** — параллельный проигрыш сыгранных нот; учёт смены клавиши
      между note-on и note-off (`monitorNotes`), All-Notes-Off / All-Sound-Off.
- [x] **MIDI-экспорт** — `writePatternMidiFile()`: Standard MIDI File
      (1 трек, 480 тиков/четверть, tempo-meta, swing, gate, end-of-track).
- [x] Кнопка **MIDI** в хедере: drag файла прямо в дорожку DAW,
      клик — показать файл.

### UI

- [x] `VesperaLookAndFeel` — кастомный LookAndFeel_V4, палитра через `ColourIds`,
      нобы-цилиндры с кольцом рисок, переключаемая **тёмная / мягкая светлая**
      тема с сохранением выбора (`theme.txt`).
- [x] **IconButton** — векторные иконки Save / Sun / Moon / Log + красный бейдж.
- [x] Секции NOTES / PATTERN / VOICE / FILTER / CHARACTER / OUTPUT,
      подписи секций своим цветом, корпус с винтами.
- [x] **PatternDisplay** — пул (имена нот), тональность, транспозиция, BPM,
      число голосов, сетка шагов (высота = velocity, подпись = нота),
      playhead, `waiting for transport` при стопе.
- [x] Дисплей обновляется только при реальном изменении снапшота
      (`sameView`, таймер 30 Гц) — нет пустых репейнтов.
- [x] **COMPACT / FULL** — скрытие дисплея, окно 1280×820 → 1280×600.
- [x] Ручка **RATE** приглушается и отключается при включённом LFO **SYNC**
      (по образцу TIME/SYNC в Lunara), обновление в `updateLfoRateUi()`.
- [x] Английские подсказки на всех контролах (`TooltipWindow`, ~650 мс).
- [x] Значения параметров в UI показываются ≤ 4 знаков, хвостовые нули убраны.
- [x] Версия плагина в шапке (`v` + `JucePlugin_VersionString`).

### Пресеты

- [x] `PresetManager` — XML-пресеты `*.vesperapreset` в
      `~/Library/Application Support/Vespera/Presets`, имена санитизируются.
- [x] **Заводские пресеты** вшиты в бинарь (`FactoryPresets.h`),
      версионированная переустановка (`factory_version.txt`, версия 7).
- [x] 8 пресетов: `First Light`, `Rain Arp`, `Broken Music Box`, `Deep Pulse`,
      `Glass Steps`, `Tape Lullaby`, `Acid Walk`, `Frozen Motif`.
- [x] Дефолт при открытии свежего экземпляра — **`First Light`**;
      восстановленный хостом проект **не перезаписывается**
      (`stateRestored` / `defaultPresetApplied`).
- [x] Имя последнего пресета хранится в процессоре — переживает пересоздание
      окна редактора (хосты пересоздают его при переключении треков).
- [x] Загрузка из вшитой копии как фолбэк, если файл удалён.

### RANDOM

- [x] `randomizeParameters()` — новый key/scale, pattern, voice, filter,
      character + **посев пула аккордом из нового лада** (тоника обязательна,
      остальное перемешано → повторные нажатия не дают тот же аккорд).
- [x] **Не трогает** `mutate`, `transpose`, `noise`, `output`, защитные параметры.
- [x] **Key Lock** — RANDOM сохраняет тональность, меняя только характер.
- [x] Музыkальные диапазоны среза **по типу фильтра** (BP 300..1500 Гц,
      HP 50..220 Гц) + логарифмический разброс — Random больше не приводит
      к «глухим» и тихим настройкам (проверка: 24 ролла, silent = 0).
- [x] Sine запрещена при BP/HP (нет гармоник, голос исчезает) — вместо неё
      Triangle/Saw/Square.
- [x] Посев передаётся в audio-поток через SpinLock + атомарный счётчик
      (`publishSeed` / `applyPendingSeed`), UI показывает новый пул сразу.

### Устойчивость и диагностика

- [x] Финальный предохранитель: нефинитные → 0, конечные выбросы → кламп ±1.0.
- [x] Детект «разгона» (пик до лимитера > 32) → сброс synth/filter/character.
- [x] `ScopedNoDenormals`, проверка `isfinite` на входе Character.
- [x] Мягкие потолки в фильтре и лимитере — экстремальный резонанс не разгоняется.
- [x] **DebugLogger** — «чёрный ящик»: lock-free FIFO снапшотов
      (пики synth/char/out + все параметры + флаги), фоновый поток,
      heartbeat 2 с, история 256 блоков при аномалии,
      лог `~/Library/Application Support/Vespera/vespera_debug.log`
      (ротация 4 МБ, подавление дублей, cooldown 5 с).
- [x] Чистый лог при каждом запуске (усечение в `prepareToPlay`).
- [x] Тестовые сборки (`VESPERA_TEST_BUILD=1`) пишут во временный каталог
      и не затирают пользовательский журнал.
- [x] Кнопка **LOG** в хедере + красный бейдж при пойманной аномалии.
- [x] Флаги: `NONFINITE`, `SYNTH_HOT`, `OUT_HOT`, `HEAVY_GR`.

### Оптимизации

- [x] Кэш сырых параметров `rawParams` (`bindRawParams()` в конструкторе) —
      в audio-потоке нет строковых лукапов.
- [x] `PolySynth::setParams` не пересчитывает ADSR без реальных изменений.
- [x] `outBuffer` выделяется один раз в `prepareToPlay`, растёт только при
      большем блоке — аудио-поток не аллоцирует.
- [x] Коэффициенты фильтра пересчитываются каждые 16 сэмплов (экономия `tan`).
- [x] Снапшот паттерна для UI — по try-lock, без блокировок audio-потока.

## Известные ограничения

- UI фиксированного размера (1280×820 / 1280×600 в COMPACT), не resizable.
- Паттерн не сохраняется в пресете — он пересобирается из текущих ручек.
- `getTailLengthSeconds()` возвращает константу 8 с (реальный хвост зависит
  от Release/Mutate).
- В пуле максимум 16 нот, в паттерне максимум 16 шагов.
- Нет MIDI-выхода: генерируемые ноты не уходят наружу (только экспорт файлом).
- В CI собирается только Windows VST3 (AU/Standalone — локально на macOS).
